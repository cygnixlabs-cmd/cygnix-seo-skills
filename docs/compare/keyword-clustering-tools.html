How to choose

  • SERP-overlap clustering (grouping keywords that share Google results) is more accurate but costs a SERP fetch per keyword; text-similarity clustering is cheaper and fine for a first pass. If you want clusters turned straight into writer briefs, pick one that outputs briefs, such as our Keyword Clustering + Brief, or try the free keyword-clustering-lite skill first.
  • From an AI agent, any of these can be called through the Apify MCP server at https://mcp.apify.com.
