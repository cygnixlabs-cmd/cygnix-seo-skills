Cygnix SEO MCP: free SEO tools for Claude, Cursor and any MCP client

An open-source MCP server (npm cygnix-seo-mcp, MIT) with 5 deterministic SEO tools that run locally on your own data. No API keys and no accounts. Listed in the official MCP Registry as io.github.cygnixlabs-cmd/cygnix-seo-mcp.

ToolWhat it does
cluster_keywordsGroups a keyword list into topical clusters and picks a pillar keyword per cluster (one cluster ≈ one page)
classify_search_intentLabels keywords informational / commercial / transactional / navigational, with the matching signal
find_keyword_cannibalizationReads GSC CSV (Query + Page) and flags queries where your own pages compete, ranked HIGH/MEDIUM/LOW, with a fix
check_title_metaScores title tags and meta descriptions (0–100): char + pixel truncation, keyword placement, CTR hooks
content_brief_outlineBuilds a brief from your keyword: intent, title options, meta draft, slug, H2 outline, questions to answer, on-page checklist

Install

Claude Code:

claude mcp add cygnix-seo -- npx -y cygnix-seo-mcp

Claude Desktop, Cursor and other stdio clients:

{"mcpServers": {"cygnix-seo": {"command": "npx", "args": ["-y", "cygnix-seo-mcp"]}}}
